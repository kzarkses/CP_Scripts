# CP icon pack — which Lucide glyphs get embedded.
#
#   <LuaName> = <lucide-file-name>
#
# LuaName is how the icon is called: UI.Icons.<LuaName>(x, y, size, r, g, b, a).
# The right-hand side is a file in Lucide/lucide-main/icons/ WITHOUT the .svg.
#
# Adding an icon is one line here plus a re-run of build_pack.mjs. Only the
# glyphs listed below are embedded — the other ~1700 stay out of the repo.
#
# A name already defined procedurally in Icons.lua is SKIPPED, with a warning:
# the hand-drawn set was authored at the same optical weight as Lucide (stroke
# 2/24) and some of it — the filled transport triangles above all — reads
# better than an outline at the 14 px a session cell gives it. Adding here,
# replacing never, until a glyph is judged one at a time.
